## 先に共有：元リポジトリの実行コマンドは、いまの Flask では動きません

README に載っている実行コマンドはこれです。

```
set FLASK_APP=app
set FLASK_ENV=development
flask run
```

**`FLASK_ENV` は Flask 2.3 で廃止され、現在の Flask では効きません。**
公式ドキュメント（3.1.x）の CLI のページに、この変数はもう出てきません。
いまの書き方はこうです。

```
flask --app app run --debug
```

- リポジトリの最終更新は **2023年7月**。当時は Flask 2.2 系で、まだ動いていました
- 現在の最新は **Flask 3.1.3**（Python 3.9 以上が必要）
- ついでに、README の PowerShell の例は引用符が全角（`“app“`）になっていて、そのままでは動きません

この回では **`app.py` の中身は元リポジトリ通り**にして、**コマンドだけ現在の書き方**にするのが
よいと考えています。生徒が写したコードは動かないと意味がないためです。

なお、このサンプルには `if __name__ == "__main__": app.run()` が入っているので、
**`python app.py` でも起動できます。**環境変数を触らずに済むぶん、こちらのほうが簡単です。
