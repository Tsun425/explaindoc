## 各論の決定

### `@app.route` の教え方（Q7）★この回の最大の制約
**「関数に貼る荷札」の比喩で通す。仕組みには踏み込まない。**

- 「この関数は `/` を開いたときに呼ばれます、という荷札を関数に貼っている」
- **1枚だけ**「この `@` は**デコレータ**という書き方です。仕組みはいずれやります」と
  **名前を置いておく。**名前を知らないと検索できないため
- 「関数を引数に渡す」の話には**入らない**。入ると今日の本題が終わらない

### PowerShell の実行ポリシー（Q9）
**注意書きを1枚入れる。** 環境構築時に仮想環境の有効化まで確認する予定は無いとのこと。

```
venv\Scripts\Activate.ps1 : このシステムではスクリプトの実行が無効になっているため…
```
対処: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`

### コマンド（元リポジトリから変更する）
元 README のコマンドは **2023年7月時点のもので、いまの Flask では動かない。**

| | 元リポジトリ | このスライド |
|---|---|---|
| 起動 | `set FLASK_ENV=development` → `flask run` | **`python app.py`** を主役に |
| | | `flask --app app run --debug` は注記で添える |
| シェル | Mac/CMD/PowerShell の3種併記 | **PowerShell のみ** |

- **`FLASK_ENV` は Flask 2.3 で廃止済み。**現在の公式CLIドキュメントに記載なし
- 元 README の PowerShell 例は引用符が全角（`“app“`）で、そのままでは動かない
- サンプルに `if __name__ == "__main__": app.run()` があるので `python app.py` で起動できる。
  環境変数を触らずに済むぶん、こちらが簡単
- **`app.py` の中身は元リポジトリ通り。**`app.run(debug=True)` にすると
  自動で読み直してくれることは、停止・再起動の枚の注意書きで1行だけ触れる

### 使うコマンド（PowerShell / Windows）
```
py -m venv venv
venv\Scripts\Activate.ps1
pip install Flask
python app.py
```
停止は <kbd>Ctrl</kbd>+<kbd>C</kbd>。仮想環境を抜けるのは `deactivate`。

### ルーティング変数の注意点
`<name>` は**スラッシュを含まない**文字列にマッチする。
そのため `/taro/suzuki` は 404 になる。ここは1枚使って触れる。
