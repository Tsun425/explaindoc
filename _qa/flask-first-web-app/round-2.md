### ❓ Q7 —【最重要】`@app.route` をどう教えるか

デコレータ未習、というのが今回いちばん大きな制約です。
最初の7行のうち、**いちばん見慣れない記号がこれ**です。

```python
@app.route("/")
def hello_world():
    return "<p>Hello, World!</p>"
```

生徒はこれまで `def` で関数を書いてきましたが、**`@` は初めて**です。
しかもこの回の主役はまさにここ（ルーティング）なので、避けられません。

- **A. 「関数に貼る荷札」として教える。デコレータという用語は出さない** ← 推奨
  「この関数は `/` を開いたときに呼ばれます、という荷札を関数に貼っている」。
  仕組みには踏み込まず、**役割だけ**を1枚で説明する。
  弱点: 厳密には正しくない。あとで正しく習い直す必要がある。

- **B. デコレータという用語を出して、仕組みも軽く説明する**
  「関数を受け取って、機能を足して返す関数」。正確です。
  弱点: **関数を引数に渡す**という発想が未習だと、ここで1コマ潰れます。

- **C. 用語だけ出して、仕組みは「次の機会に」と明言する**
  「これはデコレータという書き方です。中身は今日は気にしなくて大丈夫」。
  名前を知っていれば、あとで検索できます。

➡️ **推奨: A ＋ C の折衷。**
説明は**荷札の比喩で通し**、1枚だけ
「この `@` は**デコレータ**という書き方です。仕組みはいずれやります」
と**名前だけ置いておく**。名前を知らないと検索もできないので、名前は出したい。
でも仕組みに踏み込むと今日の本題が終わりません。

**回答:** 推奨かなまずは簡単な理解から

### ❓ Q9 — PowerShell の実行ポリシーの注意書きを入れるか

Windows で仮想環境を有効化するとき、**かなりの確率でここで止まります。**

```
venv\Scripts\Activate.ps1 : このシステムではスクリプトの実行が無効になっているため…
```

PowerShell の既定の実行ポリシーがスクリプトを禁止しているためです。
対処は1コマンドですが、**知らないと詰みます。**

- **A. 注意書きを1枚入れる** ← 推奨
  出たときの画面と、`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` を載せる。
- **B. 入れない。出たらその場で教える**
  環境構築はそちらでやるとのことなので、授業前に解決済みかもしれません。

➡️ **推奨: A。** ただし、**そちらで環境構築するときに一度有効化してしまえば
再発しません。**もし構築時にこの対処を済ませるつもりなら B でよいです。
**環境構築で仮想環境の有効化まで確認されますか？** それによります。

**回答:** まだ仮想環境の有効化は確認していません。Aでお願いします
