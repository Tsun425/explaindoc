## 確定事項

### 収録範囲
**入門の範囲**（変数・型・input/print・if・for/while・リスト・関数）。
中学生が最初の数コマで触る範囲に絞る。項目が少ないほど探しやすいため。
辞書・タプル・集合・例外処理・内包表記・クラスは**入れない**。

### 対象
**中3 〜 高校生・数コマ経験済み。**
変数と `print` は既に触っている前提で、用語をある程度使って簡潔に書く。

### 環境
**Google Colab。**
ブラウザでセルを実行する形。ファイル実行や `python3` コマンドの話は載せない。
Colab 固有として書いたもの:

- セル左の実行番号 `[1]`、■ での停止
- 変数がセルをまたいで残ること／上のセルを実行していないと動かないこと
- セルの最後の行は `print` なしでも表示されること
- `input` でセルが入力待ちになること
- メニューの「ランタイム」から再起動
- <kbd>Tab</kbd> で半角4つ分下がること

Python のバージョンは特定の数字を書かない。Colab 側で上がるため。

### 置き場所
`python/python-cheatsheet.html`（単独ファイル）。
Unix 早見表と同じ形。`python/index.html`（単元の地図）は授業スライドができてから作り、
そこからリンクする。
