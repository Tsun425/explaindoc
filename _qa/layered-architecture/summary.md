## 各論の決定

### Lombok（Q9）
**前のセクションで学習済みなので説明しない。サンプル通りに書く。**

- `@RequiredArgsConstructor` + `private final RegistRepository repository;` のまま出す
- 展開後のコンストラクタを見せる枚も、`@Autowired` の話も**入れない**
- DIの仕組みそのものも既習なので、第4章では
  「DIとは何か」ではなく **「DIがレイヤ構成にどう効くか」** に絞る

### entity と form（Q10）— 「任せる。ただし正しい情報を」
**レイヤは"処理"の役割の分け方。`Review` と `ReviewRegistForm` は処理ではなく
データなので、どの層にも属さない。** 3層を縦に貫く帯として図の横に描く。

そのうえで、**形を決めるのがどの層かは違う**、と正確に書き分ける:

- `ReviewRegistForm` … **画面の都合**で形が決まる（画面の入力項目、入力チェックのメッセージ）
- `Review` … **保存されるデータの都合**で形が決まる

2つが別々にある理由に1枚使う。**画面の都合と保存の都合は、変わるタイミングが違う。**
1つにまとめると、画面の項目を1つ増やしただけで保存側まで影響が及ぶ。

> 書き方の注意: 流派によって DTO・ドメインモデルなど呼び方も置き場所も違う。
> スライドでは **「◯◯層に属する」と断定しない。**「データの入れ物」で通す。
> `ReviewController` が `Review` を組み立てている点は、サンプル通りに扱い、批評しない。
> （これは層飛ばしではない。entity は層ではなくデータのため）

### 「次回DBに繋ぐ」の実演（Q11）
**第4章の締めに2枚使う。**

`RegistRepositoryImpl` は今 `System.out.println` だけで、DBに繋がっていない。
次のセクションでDBを学ぶ。この事実をそのまま疎結合の御利益として見せる:

> DBがまだ無くても、画面と業務処理は完成させられる。
> 次回このクラスの中身だけ書き換えれば本物になる。
> **`ReviewController` も `RegistServiceImpl` も変更ゼロ。**

これが無いと第4章は「そういうものらしい」で終わる。次回への橋渡しも兼ねる。

### MVCとの関係（Q12）
**入れる。4枚。ただし扱いは軽く。**

- MVCモデルの **M** ＝ サービス層 ＋ インフラ層
- Spring MVC の **M** ＝ Controller と View の間のデータ受け渡し場所
- 「同じ M が別のものを指す」の2点だけ図で示し、深追いしない

### やってみよう（Q13）
**分類クイズ＋NG探しの3問。** 答えは `<details>` で隠す。

1. 次のクラスはどの層か（`ReviewController` / `RegistServiceImpl` / `Review` …）
2. 次のコードはどこがNGか（`ReviewController` が `RegistRepository` を直接呼ぶ）
3. `RegistServiceImpl` を別の実装に差し替えたい。**何ファイル触るか**

3問目は疎結合の御利益を**数で**実感させるためのもの。必ず入れる。
実際にコードを書かせる課題は出さない（90分の最後に新規コーディングは厳しい）。

## 実装上のメモ

### 縦積み図の作り方
テンプレートの `.flow` は `display:flex` の**横並び**で、縦積みの部品が無い。
新しい部品は足さず、**`.flow` に `flex-direction:column` の修飾クラスを1つ**足して
既存の `.box` / `.arrow` をそのまま縦に並べる。矢印は `→` を `↓` に差し替える。
配色・角丸・影は既存のCSS変数のまま。新しい色は定義しない。

### 使うテンプレート部品
`cover` / `slide` / `eyebrow`+`part` / `code`（`code-head` + 言語名 + コピーボタン）/
`out` / `note`（無印・`warn`・`do`）/ `try` + `details` / `table` / `flow`。
`.latin` は 分野ラベル `Java`、章番号、日付、コードブロックの言語名にのみ当てる。

### 書かないこと
- 「よくあるエラー」の一覧（CLAUDE.md）。`cs/how-to-get-unstuck.html` へ誘導する
- 「フォルダ」という語。**「ディレクトリ」**と書く
