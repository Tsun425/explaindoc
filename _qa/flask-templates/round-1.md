## 先に共有：元リポジトリの該当ブランチの中身

**`01_04_templates`** — `app.py` は 11行。差分は実質2行です。

```python
from flask import Flask
from flask import render_template   # ← 追加

app = Flask(__name__)

@app.route("/")
def hello_guri():
    return render_template('index.html')   # ← 文字列を返すのをやめた

if __name__ == "__main__":
    app.run()
```

これに `templates/index.html`（ただの HTML。`<h1>` と `<p>` が3つ）が付きます。

**`01_05_templates_2`** — ここで Jinja の記法が3つ出てきます。

```python
list =[ 'test1', 'test2', ... 'test9' ]        # ← ① 変数名が list

@app.route("/<name>")                          # ← ② ルートが / から /<name> に変わる
def hello(name):
    return render_template('index.html', name=name, list=list)
```

```html
<h1>Hello,{{ name }}!</h1>
{% for test_message in list %}
    {% if loop.index % 2 == 0 %}               <!-- ← ③ 偶数番目だけ表示 -->
    <li>{{test_message}}</li>
    {% endif %}
{% endfor %}
```

**この回で生徒が覚えることは、実質この4つだけです。**

1. `templates/` ディレクトリに HTML を置く（場所が決まっている）
2. `render_template('index.html')` で、その HTML を返す
3. `render_template(..., name=name)` で値を渡し、HTML 側で `{{ name }}` と書く
4. HTML の中で `{% for %}` / `{% if %}` が書ける

量としては前回より少ないので、**「なぜテンプレートに分けるのか」と
「置き換えはサーバー側で起きている」**に枚数を使う構成を考えています。

そのうえで、元コードには**そのまま教えたくない箇所が3つ**あります。Q3・Q4・Q5 です。

### ❓ Q5 — `{% if loop.index % 2 == 0 %}`（偶数番目だけ表示）を入れるか

元コードの `{% if %}` の例はこれです。

```html
{% for test_message in list %}
    {% if loop.index % 2 == 0 %}
    <li>{{test_message}}</li>
    {% endif %}
{% endfor %}
```

これを教えるには、**ついでに3つ説明することになります。**

1. `%` が剰余（割った余り）であること
2. `loop` という**どこにも定義していない変数**が使えること
3. `loop.index` が **1から始まる**こと（`0` ではない）

「偶数番目だけ表示する」こと自体に意味がないので、説明のコストに対して得るものが薄いです。

- **A. `{% if %}` の例を差し替える** ← 推奨
  ```html
  {% if messages %}
      <ul>{% for m in messages %}<li>{{ m }}</li>{% endfor %}</ul>
  {% else %}
      <p>まだ何もありません。</p>
  {% endif %}
  ```
  **リストが空のときに別の表示を出す。**実際のWebアプリで必ず書く形です。
  `{% else %}` もついでに入ります。
- **B. 元コードどおり `loop.index % 2` で教える**
- **C. A を本編にして、`loop.index` は補足1枚で名前だけ置く**

➡️ **推奨: C。** 本編は A。`loop.index` は
「番号を振りたいときに使えるものがある」と1枚だけ置いておく。
前回の「デコレータの名前だけ置く」と同じやり方です。

**回答:** Cで

### ❓ Q6 — 「置き換えはサーバー側で起きている」を見せるか

ここが今日いちばん大事な概念だと考えています。

生徒は `{{ name }}` を見て、**ブラウザが置き換えていると思いがち**です。
実際は**サーバーが HTML を組み立ててから送る**ので、
ブラウザに届いた時点で `{{ name }}` は**どこにも残っていません。**

確かめ方は、ブラウザで**ページのソースを表示**する（<kbd>Ctrl</kbd>+<kbd>U</kbd>）だけです。
`{{ name }}` ではなく、置き換わった後の文字が出ます。

➡️ **推奨: 2枚使う。**
1枚で「サーバーで組み立ててから送る」の図、1枚で「ソースを表示して確かめる」。
前回の「リクエストとレスポンス」の図を再利用して、
レスポンスの中身が HTML になった形で描きます。

**回答:**　2枚使いましょう

### ❓ Q7 — `TemplateNotFound` と、HTML を直しても変わらない問題

この回で生徒が詰まるのは、ほぼこの2つです。**どちらも入れたいです。**

**(a) `TemplateNotFound: index.html`**
`templates` のつづりを間違えた、`app.py` と同じ階層に置いていない、
`index.html` を `templates/` の外に作った。**ディレクトリの位置の問題**です。

**(b) HTML を直して保存したのに、ブラウザが変わらない**
これは**仕様です。** Flask は、デバッグを有効にしていないと
テンプレートを読み直しません（起動時のものを使い続けます）。
前回のルール「直したら止めて起動し直す」のままでも進めますが、
HTML はこの回で何度も直すので、毎回止めるのはかなり手間です。

- **A. この回から `app.run(debug=True)` に変える** ← 推奨
  ```python
  if __name__ == "__main__":
      app.run(debug=True)
  ```
  HTML も `app.py` も、保存したら読み直されます。1枚使って説明する。
  「本番では切る」ことも1行だけ添えます。
- **B. 前回どおり `app.run()`。毎回止めて起動し直す**
  覚えることは増えませんが、HTML をいじるたびに <kbd>Ctrl</kbd>+<kbd>C</kbd> です。

➡️ **推奨: A。** ここで入れておくと、以降ずっと楽になります。
(a) は「ディレクトリの位置」の枚で、エラーメッセージを載せて扱います。

**回答:** とりあえずBにして毎回起動しなおすことを伝えて下さい
