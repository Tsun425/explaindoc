### Q7（B）について、1つだけ念押し

B で進めますが、理由を正確に書いておきます。
**Flask は、デバッグを有効にしていないとテンプレートを読み直しません。**
起動したときの `index.html` を、ずっと使い続けます。

つまり生徒がこうなります。

1. `index.html` を直して保存する
2. ブラウザを再読み込みする
3. **何も変わらない**
4. 「保存できてないのかな」と、同じことを何度も繰り返す

一人で進めるぶん、ここは**自力では絶対に抜けられません。**
なので B でいく代わりに、**この症状を先に書いた枚を、HTML を初めて直す直前に置きます。**
「変わらなかったら、まずターミナルに戻って <kbd>Ctrl</kbd>+<kbd>C</kbd> → `python app.py`」と、
手順の形で。これは Q11 の話につながります。

### ❓ Q13 — HTML の「枠」をどう扱うか

HTML 初見の生徒に `templates/index.html` を書かせるとき、これが全部目に入ります。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>自己紹介</title>
</head>
<body>
    <h1>Hello, ゲスト!</h1>
</body>
</html>
```

**今日の主題に関係あるのは `<body>` の中だけです。**
`DOCTYPE` `meta charset` `viewport` を全部説明すると、それだけで10枚使い、
Flask の話に戻れません。

- **A. 枠は「毎回同じ決まり文句」として1枚で渡し、中身だけ書かせる** ← 推奨
  「この枠は、どの HTML でも同じです。意味は別の回でやります。
  いまは**ここから下だけ**見てください」と、`<body>` の中に矢印を向ける。
  説明するタグは **`<h1>` `<p>` `<ul><li>` の3つだけ**。
  「開いたら閉じる」も1枚。計4枚。
- **B. 枠の各行の意味も、簡単に説明する**（+4枚）
  `charset` は文字化け対策、`viewport` はスマホ表示、など。
- **C. HTML の解説は別スライドに切り出す**（`python/html-basics.html` を別途作る）
  今回はそこへリンクするだけにする。

➡️ **推奨: A。** ただし `charset=UTF-8` だけは
**「これを消すと日本語が化ける」**を1行だけ添えます。実際に消える事故があるので。

**C** も筋は通りますが、**スライドが1本増えます。** いまの優先度を教えてください。

**回答:** Aかな

### ❓ Q14 — 「やってみよう」の中身

一人で進める前提なら、**答えが `<details>` に入っていることが前提になります**（これは必ず入れます）。
そのうえで、何をやらせるかです。

1. **`{{ name }}` の横に、自分の好きな文を足す**（HTML を直して、起動し直す練習）
2. **「好きなもの」のリストを、自分の内容に書き換える**（`messages` を直す）
3. **`/<name>` に自分の名前を入れてアクセスする**（前回のルーティング変数の復習）
4. **`<h2>` を足してみる**（習っていないタグを自分で試す）
5. **リストを空 `[]` にして、`{% else %}` 側が出ることを確かめる**

➡️ **推奨: 1・2・3・5 の4問。**
4 は「習っていないものを自分で試す」練習として魅力的ですが、
一人で進めるときは**正解が分からない問題**になるので外します。

5 は**自分でわざと壊して、予想した結果になるか確かめる**問題です。
`{% if %}` を入れた意味が、ここで回収されます。

**回答:**　推奨で
