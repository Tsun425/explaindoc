## この回で生徒が覚えること（4つだけ）

1. `templates/` ディレクトリに HTML を置く（**置き場所が決まっている**）
2. `render_template('index.html')` で、その HTML を返す
3. `render_template(..., name=name)` で値を渡し、HTML 側で `{{ name }}` と書く
4. HTML の中で `{% for %}` / `{% if %}` が書ける

## 各論の決定

### 進め方（Q11）★この回の最大の制約
**自習前提で作る。** 具体的に:

- **各章の終わりに「ここまでで、こうなっていれば正しい」の確認スライドを入れる。**
  ブラウザに何が出ているか、ターミナルに何が出ているかを**文字で明記**する
- 「出ない」「変わらない」ときの**分岐をその場に書く**。あとで探させない
- 「やってみよう」の答えは `<details>` に入れる（必須）

### HTML の扱い（Q13=A）
**枠は「毎回同じ決まり文句」として1枚で渡し、`<body>` の中だけ説明する。**

- 説明するタグは **`<h1>` `<p>` `<ul><li>` の3つだけ**
- 「開いたら閉じる」を1枚
- `DOCTYPE` / `head` / `viewport` の意味には**踏み込まない**（別の回）
- ただし **`charset="UTF-8"` だけは「消すと日本語が化ける」を1行**添える
- HTML を別スライド（`python/html-basics.html`）に切り出す案は**採らない**

### 元コードから変える点（3か所）

| | 元リポジトリ | このスライド | 理由 |
|---|---|---|---|
| リストの変数名 | `list` | **`favorites`** | `list` は Python の組み込みの名前。潰すと `list()` が使えなくなる。題材（自己紹介の「好きなもの」）に合う名前にした |
| リストの中身 | `test1`〜`test9` | **「ラーメン / ゲーム / 猫」** | 表示されたとき何が起きたか分かる |
| `{% if %}` の例 | `loop.index % 2 == 0` | **`{% if favorites %}` / `{% else %}`** | 偶数番目だけ表示することに意味がない。空のときの別表示は実際に必ず書く |

- `list` を避けることは**注意書き1枚**で扱う
- `loop.index` は**補足1枚で名前だけ置く**（Q5=C）。前回の「デコレータ」と同じやり方
- 生徒は**元の Udemy 動画を見ていない**ため、変数名を変えてもズレない

### ルート（Q4=A）
**`/` と `/<name>` の両方を残す。**

前回の完成コードが既に両方持っているので、**両方を `render_template` に置き換える**形になる。
**同じ HTML を、違う値で2回使う** —— テンプレートの利点そのものなので、ここを説明の山場にする。

```python
@app.route("/")
def hello_world():
    return render_template('index.html', name="ゲスト", favorites=favorites)

@app.route("/<name>")
def hello(name):
    return render_template('index.html', name=name, favorites=favorites)
```

関数名は前回のまま（`hello_world` / `hello`）にした。関数名を変える話は今日の主題ではない。

### 置き換えはサーバー側で起きている（Q6）
**2枚使う。**

1. 図。前回の「リクエストとレスポンス」の `.flow.vert` を再利用し、
   サーバーの中で `app.py` ＋ `index.html` → 組み立て → レスポンス、と見せる
2. ブラウザで**ページのソースを表示**（<kbd>Ctrl</kbd>+<kbd>U</kbd>）して、
   `{{ name }}` が**どこにも残っていない**ことを自分で確かめる

生徒は `{{ name }}` をブラウザが置き換えていると思いがち。ここを潰す。

### HTML を直しても変わらない問題（Q7=B の代償）
`app.run()` のままなので、**Flask はテンプレートを読み直さない。**
起動時の `index.html` を使い続ける。一人で進める生徒は**自力では抜けられない。**

対応: **HTML を初めて直す直前に、症状と対処を手順の形で1枚置く。**

> 直して保存した → ブラウザを再読み込みした → **何も変わらない**
> → ターミナルに戻って <kbd>Ctrl</kbd>+<kbd>C</kbd> → `python app.py`

前回のルール「直したら止めて起動し直す」と同じ。**ルールを変えない**ぶん覚えることは増えない。

### `TemplateNotFound`
1枚使う。分岐を3つ書く（`templates` のつづり / `app.py` と同じ階層か / HTML が `templates/` の中にあるか）。

### HTML の内容（Q8=A）
**自己紹介ページ。** `{{ name }}` への挨拶 ＋ 「好きなもの」のリスト。
次回（`02_top`）がメモ帳アプリのトップページなので、今回は人に依存しない題材にして、次回からメモに移る。

### やってみよう（Q14=推奨）4問
1. `{{ name }}` の横に自分の好きな文を足す（**HTML を直して、起動し直す練習**）
2. 「好きなもの」のリストを自分の内容に書き換える（`messages` を直す）
3. `/<name>` に自分の名前を入れてアクセスする（前回の復習）
4. **リストを空 `[]` にして、`{% else %}` 側が出ることを確かめる**（わざと壊して予想を確かめる）

元案の「`<h2>` を足してみる」は**外した**。一人で進めるときは正解が分からない問題になる。

前回と同じ。出典としてリポジトリのリンクを載せる。説明文・図・構成・登場人物名（「ぐり主任」）は使わない。
