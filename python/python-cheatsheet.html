01Colab の使い方

操作意味
Shift + Enterセルを実行して、次のセルへ進む
Ctrl + Enterセルを実行して、その場に留まる
＋ コードコードセルを追加する
セル左の [1]実行した順番。実行するたびに増える
セル左の ■実行を止める
変数はセルをまたいで残る

上のセルで作った変数は、下のセルでもそのまま使えます。逆に、上のセルを実行していないと下のセルは動きません。おかしくなったら、いちばん上から順に実行し直してください。

セルの最後の行だけは print を書かなくても結果が表示されます。ただし途中の行は表示されないので、print を書く癖をつけてください。

02print — 表示する

書き方意味
print("こんにちは")文字をそのまま表示
print(x)変数の中身を表示
print("点数", x)カンマで並べる。間に空白が入る
print(f"点数は{x}点")文の中に変数を埋める（f を忘れずに）
print("a", end="")改行しない
print()空の行を1つ出す
Python
score = 85
print(f"点数は{score}点です")
実行結果点数は85点です
引用符とカッコは半角

全角の ” や （ はエラーになります。コードを打つときは日本語入力をオフにしてください。文字列の中身だけは日本語で構いません。

03変数と型

書き方意味
x = 10右の値を x に入れる
x = x + 1いまの x に1足して入れ直す
a, b = 1, 2まとめて入れる
type(x)型を調べる
型中身例
int整数10
float小数3.14
str文字列"こんにちは"
bool正しいか否かTrue / False
list複数の値[1, 2, 3]
型を変える意味
int("10")文字列 → 整数
float("3.14")文字列 → 小数
str(10)数 → 文字列
"10" と 10 は別物

引用符が付いていれば文字列です。"10" + "5" は "105"、10 + 5 は 15 になります。計算したいなら int() で数に変えてください。

変数の名前に使えるのは英小文字・数字・アンダースコア。数字から始めることはできません。

04数の計算

記号意味例

*かける3 * 2 → 6

//わって整数部分だけ7 // 2 → 3

書き方意味
len(s)文字数

s[0:3]先頭から3文字（3 は含まない）

06input — キーボードから受け取る

書き方意味
name = input("名前: ")入力欄がセルの下に出る
n = int(input("数: "))数として使うなら int() で包む
Python
age = int(input("年齢を入れてください: "))
print(f"来年は{age + 1}歳ですね")
実行結果年齢を入れてください: 15

input が返すのは必ず文字列

15 と打っても、Python が受け取るのは "15" です。そのまま足し算すると失敗します。計算に使うなら int() を忘れずに。

入力欄が出ている間、セルは入力を待って止まっています。何も起きないように見えたら、セルの下に入力欄が出ていないか確認してください。

07if — 条件で分ける

Python
score = 75

if score >= 80:
    print("合格")
elif score >= 60:
    print("あと少し")
else:
    print("もう一度")
実行結果あと少し
くらべる記号意味
==等しい
!=等しくない
> <大きい・小さい
>= <=以上・以下
in含まれているか
条件をつなぐ意味
and両方とも正しいとき
orどちらか正しければ
not正しくないとき
= と == は別

= は「入れる」、== は「等しいか比べる」です。if の中で使うのは == のほう。10 < x < 20 のように、数学と同じ形でつなぐこともできます。

09while — 条件が続く間くり返す

Python
i = 0
while i < 3:
    print(i)
    i += 1   # これを忘れると止まらない
実行結果0
1
2
書き方意味
breakくり返しを途中で抜ける
continueこの回を飛ばして次へ
止まらなくなったら

条件がずっと正しいままだと、while は永久にまわり続けます。セル左の ■ を押して止めてください。壊れてはいません。

回数が決まっているなら for、「〜になるまで」なら while を使います。

11関数 def

Python
def add(a, b):
    return a + b

kotae = add(3, 5)
print(kotae)
実行結果8
書き方意味
def 名前(引数):関数をつくる
return 値呼び出したところへ答えを返す
名前(値)呼び出して動かす
def f(x, y=10):省略されたら y は 10
def を書いただけでは動かない

def は「こういう手順を用意する」という宣言です。呼び出して初めて実行されます。Colab では、定義したセルを1回実行しておけば、そのあとどのセルからでも呼び出せます。

return は値を返すだけで、画面には出しません。表示したいときは、呼び出した側で print します。return のない関数を print すると None と出ます。

13記号とインデント

記号意味
:「この下にブロックが続く」合図
半角スペース 4 つインデント。ブロックの中身を表す
#ここから行末までコメント（実行されない）
=入れる
==等しいか比べる
" " ' '文字列。どちらでもよい
[ ]リスト、または何番目かの指定
( )関数の呼び出し、計算の順番
Python
if x > 10:
    print("中")   # 4つ下げた行が if の中身
print("外")       # 戻した行は if と関係なく必ず動く

Python では字下げが意味を持ちます。: で終わる行の次は、必ず右にずらします。ずれ方がそろっていないと動きません。Colab では Tab を押せば 4 つ分下がります。

全角スペースは見えないエラーのもと

字下げに全角スペースが混ざっても、見た目ではほとんど分かりません。うまくいかない行は、行頭を Backspace でいったん全部消して、半角で打ち直すのがいちばん速いです。
